# WebTrace

WebTrace 是一个本地优先的 Chrome Manifest V3 扩展，用来回答：我每天打开某个网站多少次、真正看了多久、分别在什么时间打开。

## 功能

- 手动添加多个 HTTP/HTTPS 网站，自动归一化为可注册主域名并覆盖其子域名。
- 区分有效打开与刷新、站内跳转、同站子标签继承，避免重复计数。
- 只在目标标签页活动、Chrome 窗口前台且未最小化、页面可见、设备未锁屏时累计有效时长。
- 点击工具栏图标打开或聚焦分析页，查看单个网站最近 7 天的打开次数、有效时长和逐次访问明细。
- 支持停止或恢复后续统计，以及在明确确认后删除单个网站的全部历史；停止和删除都保留网站配置。

## 数据与隐私

网站配置保存在 `chrome.storage.local`，会话映射保存在 `chrome.storage.session`，访问记录保存在扩展自己的 IndexedDB。运行时代码不发送网络请求、不加载远程代码，也不保存完整 URL、路径、查询参数或网页标题。

记录默认长期保留，直到用户删除对应网站历史或卸载扩展。新增或重新启用网站不会追溯当前已打开页面，必须离开后再次进入才会形成新记录。

## 安装与使用

1. 在 Chrome 扩展程序管理页启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，并选择本仓库目录。
3. 点击 WebTrace 工具栏图标进入分析页。
4. 在“管理网站”中填写名称和域名或完整页面 URL。
5. 从站外进入已配置网站后，回到分析页查看统计结果。

修改扩展文件后，需要在扩展程序管理页重新加载未打包扩展。

## 开发验证

项目没有构建步骤。安装锁定的测试依赖并运行自动测试：

```sh

```
